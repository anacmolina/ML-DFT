# AbflowMC code base

This repository contains the code base for the abflowMC method presented in: 

Active learning of Boltzmann samplers and potential energies with quantum mechanical accuracy
Ana Molina-Taborda, Pilar Cossio, Olga Lopez-Acevedo, Marylou Gabrié
(https://arxiv.org/abs/2401.16487)

The code base contains 3 folders:
- `package/aflowmc`: contains the main code base for the abflowMC method.
- `molecular_dynamics`: contains the scripts to generate the initial MD data using Ase and GPAW.
- `experiments`: regrouping the scripts that were used to generate the results presented in the paper.
